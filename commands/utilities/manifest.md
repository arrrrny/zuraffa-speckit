# speckit.zuraffa.manifest

**Category**: Utilities
**CLI Equivalent**: `dart run zuraffa:zfa manifest`
**Description**: List all available ZFA capabilities and plugins

## Usage

```
zfa manifest [arguments]
```

## Options

- `-f, --format`: Output format (json, mcp)

## Examples

```
# List all capabilities
zfa manifest

# JSON output
zfa manifest --format=json
```

## Help

For more information, run:
```
zfa help manifest
```
