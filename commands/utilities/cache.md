# speckit.zuraffa.cache

**Category**: Utilities
**CLI Equivalent**: `dart run zuraffa:zfa cache`
**Description**: Generate Cache logic for data caching

## Usage

```
zfa cache [arguments]
```

## Options

- `-o, --output`: Output directory (defaults to lib/src)
- `-f, --force`: Overwrite existing files
- `--dry-run`: Preview without writing files

## Examples

```
# Generate cache logic
zfa cache
```

## Help

For more information, run:
```
zfa help cache
```
