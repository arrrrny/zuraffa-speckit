# Utilities Commands

This directory contains utility commands.

## Commands

- **cache** - Generate Cache logic
- **manifest** - List all available capabilities
- **validate** - Validate JSON configuration
- **config** - Manage ZFA configuration

## Usage

```bash
speckit.zuraffa.cache
speckit.zuraffa.manifest --format=json
speckit.zuraffa.validate config.json
speckit.zuraffa.config
```
