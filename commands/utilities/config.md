# speckit.zuraffa.config

**Category**: Utilities
**CLI Equivalent**: `dart run zuraffa:zfa config`
**Description**: Manage ZFA configuration settings

## Usage

```
zfa config [arguments]
```

## Options

- `-h, --help`: Print usage information

## Examples

```
# Show current config
zfa config

# View help
zfa config --help
```

## Help

For more information, run:
```
zfa help config
```
