# speckit.zuraffa.doctor

**Category**: Management
**CLI Equivalent**: `dart run zuraffa:zfa doctor`
**Description**: Show information about installed tooling and diagnose issues

## Usage

```
zfa doctor [arguments]
```

## Options

- `-h, --help`: Print usage information

## Examples

```
# Check tooling status
zfa doctor

# Get help
zfa doctor --help
```

## Help

For more information, run:
```
zfa help doctor
```
