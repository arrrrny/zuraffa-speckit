# speckit.zuraffa.apply

**Category**: Management
**CLI Equivalent**: `dart run zuraffa:zfa apply`
**Description**: Execute a previously generated plan

## Usage

```
zfa apply [arguments]
```

## Options

- `--plan-id` (mandatory): The ID of the plan to execute

## Examples

```
# Execute a plan
zfa apply --plan-id=abc123
```

## Help

For more information, run:
```
zfa help apply
```
