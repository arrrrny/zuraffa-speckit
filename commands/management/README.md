# Management Commands

This directory contains management commands.

## Commands

- **apply** - Execute previously generated plan
- **plugin** - Manage plugins
- **doctor** - Show tooling information
- **shadcn** - Generate Shadcn UI widgets

## Usage

```bash
speckit.zuraffa.apply --plan-id=abc123
speckit.zuraffa.plugin
speckit.zuraffa.doctor
speckit.zuraffa.shadcn Product --layout=list
```
