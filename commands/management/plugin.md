# speckit.zuraffa.plugin

**Category**: Management
**CLI Equivalent**: `dart run zuraffa:zfa plugin`
**Description**: Manage ZFA plugins

## Usage

```
zfa plugin [arguments]
```

## Options

- `-h, --help`: Print usage information

## Examples

```
# List plugins
zfa plugin

# Get help
zfa plugin --help
```

## Help

For more information, run:
```
zfa help plugin
```
