# speckit.zuraffa.entity

**Category**: Structure
**CLI Equivalent**: `dart run zuraffa:zfa entity`
**Description**: Create and manage Zorphy entities

## Usage

```
zfa entity [arguments]
```

## Options

- `-h, --help`: Print usage information

## Notes

This is a passthrough to zorphy_cli for Zorphy entity management.

## Examples

```
# Create new entity
zfa entity create Product

# Get help
zfa entity --help
```

## Help

For more information, run:
```
zfa help entity
```
