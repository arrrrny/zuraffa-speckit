# speckit.zuraffa.create

**Category**: Structure
**CLI Equivalent**: `dart run zuraffa:zfa create`
**Description**: Create architecture folders or pages

## Usage

```
zfa create [arguments]
```

## Options

- `-h, --help`: Print usage information

## Examples

```
# Create new structure
zfa create

# Get help
zfa create --help
```

## Help

For more information, run:
```
zfa help create
```
